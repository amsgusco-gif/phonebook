เปิดสมุดโทรศัพท์

⚠️ ยังไม่ได้ตั้งค่าลิงก์แอป

ผู้ดูแลต้องแก้ค่า EXEC_URL ในไฟล์ index.html ให้เป็นลิงก์ Web App (/exec) ก่อน

🌐 กรุณาเปิดด้วยเบราว์เซอร์

แอปนี้ถูกเปิดอยู่ในแอปแชต จึงเพิ่มลงหน้าจอโฮมไม่ได้ แตะเมนู ⋯ แล้วเลือก เปิดใน Safari / เปิดในเบราว์เซอร์

📱 iPhone / iPad

  1. เปิดหน้านี้ด้วย Safari
  2. แตะปุ่ม แชร์ ด้านล่างจอ
  3. เลื่อนลง แล้วแตะ เพิ่มไปยังหน้าจอโฮม
  4. แตะ เพิ่ม มุมขวาบน

🤖 Android

  1. เปิดหน้านี้ด้วย Chrome
  2. แตะเมนู ⋮ มุมขวาบน
  3. เลือก เพิ่มลงในหน้าจอหลัก หรือ ติดตั้งแอป
  4. แตะ เพิ่ม / ติดตั้ง

ติดตั้งครั้งเดียว ต่อไปแตะไอคอนสมุดโทรศัพท์บนหน้าจอเพื่อเปิดใช้งานได้ทันที
